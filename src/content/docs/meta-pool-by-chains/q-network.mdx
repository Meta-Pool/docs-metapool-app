### About Project Q

Q is a blockchain that combines a public, open and decentralized ledger with the transparency and predictability of enforceable private contracts, aimed at use cases that want decentralization with scalability and dependability.

For deeper protocol detail, see Project Q / Q Network public materials. The sections below are a short primer only.

#### Terminology

**Q Constitution**

The Q constitution lays down the rights and obligations of all stakeholders of the Q system. It provides certainty and predictability for everyone using Q or building on it.

**Q Blockchain**

The Q blockchain is an independent blockchain based on Ethereum technology, which lets Q benefit from Ethereum’s existing ecosystem (developer community, protocols, applications, and tokens).

**Validators and Root Nodes**

Q blockchain is maintained by validators and root nodes.

Validators maintain the Q blockchain. They validate transactions, form blocks, and record valid transactions on the Q blockchain. Non-valid transactions are rejected. In maintaining the Q blockchain, they respect and implement the rules as laid down in the Q constitution, including running up-to-date Q protocol software and a Q fullnode.

Root nodes monitor validators to ensure compliance with the Q constitution. They form a second security and governance layer. Root nodes run a Q fullnode but do not validate transactions, amend the chain, reverse transactions, or reorganize the blockchain.

**Consensus**

The Q blockchain runs on a permissionless peer-to-peer network. Network consensus uses a delegated proof-of-stake (DPoS) mechanism: a defined subset of nodes (validators) form consensus on network state. Users vote for witnesses; top witnesses validate transactions. Voting power can be delegated. Votes are weighted by stake. DPoS is intended to support high throughput and predictable transaction costs.
