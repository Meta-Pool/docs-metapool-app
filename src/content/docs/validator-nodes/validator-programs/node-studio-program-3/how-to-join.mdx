Node Studio is designed for new validators or small teams looking to start validating on NEAR without advanced technical knowledge.


<Aside type="caution">

**Historical cohort docs vs live Node Studio** — Program #1 / #2 / #3 pages in these docs record **cohort-specific published terms** (including **5 NEAR**/month and **40,000 NEAR** delegation on Monthly Payment pages). Those figures are **historical / cohort terms**, not a current universal rate card. Live product: [https://nodestudio.metapool.app](https://nodestudio.metapool.app/). Marketing there (verified 2026-09-22) advertises from **$25 or less**, and callouts for **10,000 NEAR** (apply for delegation support) and **25,000 NEAR** (ready to launch). Confirm current price and open programs on the live site before applying or paying.

</Aside>


Meta Pool has run multiple Node Studio program cohorts (**Program #1**, **#2**, and **#3** are documented in these docs; Program #1’s one-year cohort is completed/closed). Cohort availability changes over time — check [nodestudio.metapool.app](https://nodestudio.metapool.app/) or contact the team for the currently open edition.

To join:

* Register for an open program edition when applications are available.
* Users are provided access to the Node Studio platform, which automates the creation and management of a validator.
* The user retains full control over their VPS (Virtual Private Server) and private keys, while the software handles deployment, configuration, and updates.
