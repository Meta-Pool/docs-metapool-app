---
title: DappNode Program
---

The DappNode program focuses on democratizing access to NEAR validation by enabling individuals and small operators to run validators through DappNode’s open-source infrastructure.

DappNode provides a local interface that allows anyone to deploy and manage nodes easily, without needing to rely on cloud services or deep technical expertise.

Integrated with Meta Pool, this program empowers users to operate their own validator using a decentralized, self-managed infrastructure, while keeping full control over their hardware and private keys.

The main goal of DappNode is to increase true network decentralization by encouraging participation from distributed operators worldwide and reducing reliance on centralized data centers.

This approach reinforces user sovereignty and ensures a transparent, secure, and community-driven validation layer for the NEAR network.

### How to Join

\
The DappNode program is designed for individuals or small operators who have been **selected by DappNode** to participate in NEAR validation using DappNode’s open-source infrastructure.

Validators participating in this program are **curated users chosen directly by DappNode**. There is no open subscription or public application process.

DappNode provides a simplified validator setup and management experience, handling deployment, updates, and configuration automatically, without requiring advanced technical knowledge.

Participants retain full control over their hardware or VPS and private keys, ensuring security and sovereignty.

For further information about eligibility, participation criteria, or operational details, **please contact DappNode directly**.
